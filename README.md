# bali-villa-website
Luxury Bali villa website

## Stack

React + Vite + TypeScript, Tailwind CSS, GSAP (`gsap` / `@gsap/react`), ESLint + Prettier.

## Getting started

```bash
npm install
npm run dev      # start dev server
npm run build    # type-check and production build
npm run preview  # preview the production build
npm run lint     # run ESLint
npm run format   # run Prettier
```

This is currently a bare technical scaffold. Page structure, sections, design tokens,
and content will be implemented from the approved Figma design.
